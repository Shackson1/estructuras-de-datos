# estructuras-de-datos

Repositorio para la materia de estructuras de datos.

## Contenido

Este repositorio contiene ejercicios, ejemplos y/o implementaciones relacionadas con la materia de estructuras de datos, desarrollados en **C#**.

Aquí se pueden incluir temas como:

- Arreglos y listas
- Pilas y colas
- Listas enlazadas
- Árboles
- Grafos
- Algoritmos de búsqueda y ordenamiento

## Objetivo

Servir como apoyo para el estudio y la práctica de los conceptos fundamentales de estructuras de datos.
